# 逐光 AI 求职助手：完整功能计划

> 2026-10-20 用户授权版本；原型框架确定。本文是功能承诺，不是已完成清单。所有未通过验收的项目默认待实现。

## 1. 产品原则与边界
- 原创 AI Native 求职全流程，计算机领域优先；参考用户自有备考帮/求职分析平台的设计，不能以包装旧项目代替原创实现。
- 先城市或先方向均可，无简历也可开始，所有页面自由跳转。AI以用户意愿为准，建议可拒绝，不强制流程。
- 保留目前已审核的功能位置、淡紫视觉、沉浸全屏、太极浮球导航与轻雾切页；管理员独立后台，不重新设计成管理系统前台。
- 多个可拖动看板娘不占布局列，主Agent作为统一入口，员工Agent任务/动作/状态可见；AI对话另有独立页面。工作态借鉴备考帮固定高度滚动气泡。
- 页面必须区分真实数据、演示数据、不可用服务；无结果如实说明，不用示例冒充成功。不得承诺获奖、满分或虚构评测成绩。

## 3. AI技术：必须真实落地
- A01 LLM网关：服务端供应商适配、按任务选型、结构化输出校验、Prompt版本、流式、取消/超时/重试/费用记录。公共知识问答与个人资料检索分离。
- A02 多Agent编排：主控规划/职责Agent真实任务调用、状态机与工具事件；员工可见，但不以多次同一提示冒充自治协作。
- A03 Function Calling/MCP：受控导航/查询/过滤/生成编辑页面块/地图规划；工具白名单、参数schema、身份继承、写操作确认、可撤销。
- A04 RAG：简历/岗位/面经/企业知识分域分租户；文档切块、Embedding向量索引、关键词+向量混合检索、重排、来源引用、增删同步。基线与增强质量对照，不能只把全文拼Prompt叫RAG。
- A05 知识图谱：节点包含岗位、技能、知识点、题目、公司、城市；关系如要求技能/先修/考察/位于。用于技能缺口解释、学习路径、面试选题；提供真实关系查询与可视化，可轻量关系表开始，不强制上Neo4j。
- A06 领域微调：优先小型开放模型LoRA，用于中文求职意图路由、岗位技能抽取/匹配理由结构化。公开许可或授权/自制脱敏样本，训练集/验证集隔离、模型卡、训练日志、基线对照；真实权重产物。仅提示词不算微调，用户私人简历默认不用于训练。训练前单独报算力/预算，不擅自付费训练。
- A07 多模态简历：图片OCR/视觉理解、文档抽取、证据定位、用户确认。复杂版式与扫描件不能静默当成空内容。
- A08 统一语音会话：ASR→用户文字→Agent→分段文本+TTS→看板娘气泡/说话动作同步，不能做成互不相干入口。播放限制时给点击启用；打断/排队/暂停/失败反馈；TTS只读最终可见回复，不读私密推理链。
- A09 工作态：固定高度气泡滚动显示可公开计划、操作事件、工具结果与错误；不是输出隐私思维链。
- A10 安全可控：不可信上传/网页指令隔离、工具授权/限流、输出安全渲染、敏感数据最少外发、引用证据/不确定性、失败拒答或转手工，不造成功。

## 4. 性能、可靠性、安全（开发即考虑）
- 模块化Vue3+TS、按路由/重依赖懒加载、图表与Live2D按需、缓存带租户/权限维度；不做每次请求全量文件扫描。
- 数据持久化/事务/迁移/索引，分页；密码单向KDF、会话HttpOnly、安全Cookie策略、服务端所有权检查与CSRF/Origin检查。
- 用户上传存私有目录：文件类型/体积校验、防路径穿越、下载鉴权、日志脱敏、删除/导出、外部模型告知/同意。账号隔离≠脱敏。
- AI长任务并发/排队背压、请求取消、超时、断路/可控重试、幂等避免重复计费；服务退出保留数据。
- 错误边界=一个模块或一次AI请求失败时其余页面能用，保留草稿、给具体失败状态、重试或取消；不以fallback示例蒙混。
- 前期以用户手测和每批最低语法/构建/接口安全/浏览器冒烟为主；后期系统化自动回归+负载抗压。绝不以“高可用”口号冒充实测容量或多副本容灾。

- 真国奖资源：本工作区“传智杯AIWeb竞赛/以前国奖的项目”；本届官方要求以竞赛要求.txt为依据。具体项目奖级、技术实现、测试数字需逐项证据，不凭文件名和文案认定。
