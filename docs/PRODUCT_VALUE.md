# 产品价值与社会/商业潜力

## 用户与痛点

目标用户：18–26 岁高校学生、应届生、转行求职者。

真实痛点不是“缺一个聊天机器人”，而是四段割裂：

1. 简历写完不知道怎么改，投递话术每次重写。
2. 岗位信息散在多个平台，企业风评真假难辨。
3. 刷题、八股、项目表达和面试脱节。
4. 面试练习缺少反馈，尤其是表达、眼神、停顿、结构。

逐光把这些串成一个工作台：简历 → 岗位 → 投递方案 → 学习 → 模拟面试 → 复盘。

## 差异化

- **不是通用聊天壳**：RAG 有引用/拒答，Tool RAG 有工具检索，多 Agent 有规划，MCP 有协议。
- **隐私优先的视频面试**：端侧 MediaPipe 先算视线/头姿/光线/动作，只把关键帧和指标给 VLM，不上传原始视频。
- **可解释**：RAG 回答带来源编号；知识卡片标注 AI 生成/原文答案；管理员只能看账号元数据。
- **可维护**：工具表更新只改 Tool RAG 注册表，不重建索引；题库 catalog 变更自动触发重建。

## 社会价值

- 降低求职信息不对称：把岗位、企业、租房、学习、面试放在一个可访问的 Web 工作台。
- 对没有付费咨询预算的学生，提供可解释的练习与反馈。
- 隐私友好：不把原始音视频落盘，不把个人简历/聊天内容放进公共 RAG。
- 可扩展到高校就业中心/公益求职训练营，作为低成本练习工具。

## 商业潜力（务实版）

不虚构收入，先列可验证路径：

1. **B2B2C 高校就业中心**：学校采购练习/测评账号，学生免费使用。
2. **训练营/社团合作**：按班级/项目提供模拟面试与复盘报告。
3. **增值服务**：简历深度诊断、岗位定制、面试复盘（按次/订阅）。
4. **企业招聘合作**：企业发布岗位/雇主品牌内容（必须明确标注，不做付费排名）。

当前阶段不声称已有收入/上万用户；需要先做小范围用户验证。

## 验证计划（提交前可做）

- 10–20 位同学试用：完成一次简历→岗位→面试流程。
- 记录：完成率、平均用时、RAG 引用正确率、面试反馈可理解度。
- 问卷：最有用模块、最不信任的 AI 输出、是否愿意继续使用。
- 把结果写进 PDF/视频，而不是只写“很有价值”。

## 与评分表对应

- 实用性 10%：真实场景 + 完整链路 + 用户验证。
- 社会价值 5%：信息公平、隐私友好、低成本。
- 商业潜力 5%：高校/训练营/增值服务路径，不虚构数据。
- 创新性 25%：全生命周期闭环、隐私友好视频面试、双 RAG（知识/工具）。
