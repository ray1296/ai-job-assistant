## 安全检查结果

- 未登录访问 /api/profile → 401
- 缺 CSRF 的写请求 → 403
- 未登录 RAG → 401；已登录只读 RAG 豁免 CSRF（限流 30/分钟）
- /orig/../server/index.mjs、/live2d/../../server/index.mjs → 404
- 管理员用户列表只返回 id/email/role/displayName/createdAt/简历数/面试数
- CSP、X-Content-Type-Options、X-Frame-Options、Referrer-Policy、Permissions-Policy 均存在
- 静态资源路径有 path.resolve + startsWith(root+sep) 校验
- 数据集解析使用 spawn 参数数组，无 shell；扩展名白名单；8MiB 限制；25s 超时
- SQL 均为参数化；唯一的动态表名 tableCount() 只接受硬编码常量
- 前端 v-html 只用于 escapeHtml 后的代码填空
- 地图信息窗使用 textContent，不拼 HTML

## 性能检查

- RAG 3762 chunk：BM25 首查构建缓存；向量余弦 3762×1024，单次可接受
- 检索 Top60+Top60 → RRF → rerank 24 → 6；上下文上限 8k 字
- embedding 批量 10 条，增量按 content hash
- 静态资源长缓存；HTML no-cache
- 限流：API 300/分钟/IP；登录 20/15 分钟/IP；RAG 30/分钟/用户
- 主模型回答仍是主要延迟来源（RAG 实测 5–14s），不是检索

## 仍存在的风险（不假装为零）

1. 高德 JS SDK 需要 unsafe-eval；CSP 不能做到最严格。
2. 代码已支持 HTTPS/X-Forwarded-Proto 自动 Secure + HSTS，但当前本地是 HTTP；正式部署仍必须启用 HTTPS/可信代理。
3. RAG 评测只有 18 条小样本（recall/citation/refusal 1.0），0.38 阈值仍需真实用户问法扩样。
4. catalog 更新已能通过 sourceDigest 自动判断并后台重建；重建期间仍返回旧索引结果，且需要 API 费用。
5. 管理端已有单进程 3 秒幂等；多实例/多副本部署还需要 Redis/数据库级分布式锁。
6. 外部模型 API 延迟已限制 30s 并给出来源兜底，但仍不是 SLA；RAG 平均约 6.3s，最慢 20s+。
7. 面试 start guard 是代码级验证，未做真实摄像头双击 E2E。
8. Tool RAG 目前是词法检索；工具超过 20 个应换向量/学习型 router。
9. 竞赛提交材料（5–8 分钟视频、≤30 页 PDF、团队信息、公网演示/评审账号）仍未完成；这是当前最大扣分项。
