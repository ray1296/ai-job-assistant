# 网站功能清单

面向用户的功能分为 17 个页面 + 独立管理中心。状态以当前代码和本轮测试为准。

## 1. 首页 / 导航

- 落地页、品牌、职业旅程地图（17 个板块）
- 可拖动/收起的星盘导航，位置记忆，键盘可操作
- 逐光星盘：全屏宇宙星空 3D 旅程地图，18 个板块各自一颗风格化浮空星球/浮岛底座（AI 生成世界场景，带轨道环、悬浮阴影），星盘入口改为动态天体盘；每个名称直接嵌在所属星球上，避免被其他星球遮挡；移除星球下多余底座框；所有连接取消虚线底，以链环/桥面/星门/世界树/裂隙/星轨实体化；中心天盘连接，悬停点亮星球与相关连线并出现中央“法天象地”预览，点击进入对应板块；中心是单独生成的 3D 天体星盘图，叠加自转/能量扫光、光点星尘、流星和悬浮阴影；图片 webp + immutable 缓存
- 首页 bigdata_analysis 风格 Tendril 弹簧拖尾：20 条曲线跟随鼠标；透明 canvas、不拦截点击
- 左上角逐光 Logo 始终回到首页第一个板块；已在首页时回到顶部
- 就业数据大屏：标题居中；全屏时左上角显示同风格“退出全屏”按钮，非全屏隐藏
- 日间/夜间主题：头像旁一键切换，默认日间，localStorage 记忆；夜间首页黑底让拖尾更明显，全站页面同步深色
- 四只看板娘/agent、主 Live2D 看板娘、立绘兜底
- 登录/注册入口、右上角用户头像+用户名
- 页脚、移动端布局

## 1b. 项目介绍与站内通告

- 顶部“功能说明”入口 + 首页“看项目介绍”提示
- 项目介绍页按板块说明功能、入口和使用步骤
- AI 的 project_guide 工具直接读取同一份说明，不做 RAG，避免功能变化后索引不同步
- 顶部通告入口：管理员发布，用户查看并点“已阅”，未读红点
- 管理员“通告”页：发布/上线/下线/删除

## 2. 账号与会话

- 邮箱+密码注册/登录；注册可选用户名
- 邮箱格式校验；注册密码 10—128 位且必须同时包含字母和数字（允许常见符号）
- 注册成功后可直接使用同一邮箱/密码登录；退出后登录表单不会残留注册模式
- 普通用户/管理员两个入口
- 会话恢复、退出、密码修改、用户名修改
- 密码修改后撤销其他会话
- 登录限流、CSRF、同源校验

## 3. 个人信息

- 意向城市/职业方向标签
- 姓名、电话、邮箱、个人简介
- 个人照片：最多3张，上传/移除/缩略图，自动压缩，第一张作为简历主照片
- 简历解析会抽取 PDF/DOCX 内嵌图片作为候选照片，用户勾选后才保存；PDF 若有文本层，会同时提交本地逐字文本并用视觉辅助，减少“AI原文识别无效”
- 原文证据校验会归一化空格/中英文标点，并允许项目符号换行后的多数片段匹配，避免正常简历因排版差异被误拒
- 简历工作室可直接上传，也可从个人信息里已保存的照片中一键选择照片；从个人信息导入时同步照片
- 解析结果创建独立简历成功后，显示明确成功卡片和“前往简历工作室”直达按钮（自动定位新版本）
- 生图装饰是顶部 AI 内容审阅里的复选框；勾选后生成一张整页背景，AI 根据简历内容和文字/照片占用区域避开正文
- 装饰风格可选 AI 自动适配、极简、极繁、科技；提示词包含内容线索、构图/留白/色板、占用区域和明确排除项
- AI 推荐布局会真正重排板块、合并相近短板块、设置两栏，并在应用前展示结构预览
- 个人简介空时收成“添加个人简介”按钮，非空悬停可删除，不再保留空输入行
- AI 排版/审阅请求不携带照片 data URL，照片只在保存文档时保留，避免多页/带照片简历被误判“内容过大”
- 教育、项目、实习/工作多段编辑
- 技能、荣誉/证书、备注
- 保存/重新载入、版本冲突保护
- 已有简历上传：PDF/DOCX/PNG/JPEG
- AI 文本/视觉识别、原文核对、字段勾选导入
- 导入目的地：个人资料草稿 / 独立简历版本

## 4. 简历工作室

- 单文档原位编辑（双击、回车确认、Esc 取消）
- 板块/条目增删移动、撤销重做
- 模板、字号、强调色、排版
- 多版本复制/切换/删除、版本冲突保护
- 旧版纯文本迁移到结构化文档
- AI 内容审阅与逐项建议（不自动覆盖）
- 生图装饰开关（默认关）；A4 自动分页与页数提示；长板块按条目跨页并显示“续”标题，避免一页只放一个板块留下大片空白
- Word 下载、PDF 打印/另存、打印时隐藏导航
- 移动端编辑

## 5. 数据空间

- 上传岗位/企业/租房/面经数据
- 支持 CSV/TSV/JSON/NDJSON/JSONL/XML/XLSX/TXT
- 字段自动映射、AI 辅助映射、详情/原始行查看
- 岗位数据薪资折算
- 私人数据账号隔离、删除数据集
- 数据获取指南、平台数据入口

## 6. 发现岗位

- 107 条岗位目录、关键词搜索
- 方向/城市/学历/招聘类型/来源筛选
- 岗位详情、来源链接、薪资/地址
- 加入投递意向，卡片显示未确认/待保存/已确认状态
- 可按“已确认投递意向 / 未确认投递意向”筛选岗位

## 7. 投递意向与方案

- 已选岗位列表
- 投递话术草稿、自动保存、版本冲突保护
- 定制简历打开时自动执行 AI 排版优化并生成整页装饰；AI 排版超时放宽到 120 秒；AI 推荐结果直接应用，超长条目按段落拆分，避免一页一个条目；PDF 由服务端无头浏览器生成，只含简历纸张，不含浏览器页眉页脚/网站外壳
- Word 导出按内容类型对齐（姓名/联系方式居中、正文左对齐），板块和经历之间保留空行；整页背景按 A4 794×1123 放入页眉浮层，header/footer 边距归零，覆盖每一页
- 按岗位定制简历 + 投递文案（文案随定制一次生成；不再保留单独的 AI 生成/优化文案按钮）
- 事实校验（数字/技能词白名单）
- 复制文案、打开岗位/简历
- 岗位定制版本不覆盖原简历

## 8. 就业数据大屏

- 岗位/企业/城市/校招/实习统计
- 省份岗位排行、地图分布
- 平均薪资、学历/薪资分布
- 岗位描述词云
- 城市切换、全屏、滚动图表
- 移动端布局

## 9. 城市与通勤地图

- 高德地图、标准/卫星/路网/路况图层
- 岗位/租房点、地铁站/线路（地铁站按岗位/租房城市动态加载，不再固定 25 条）
- 周边搜索（商场/加油站/小区/景点/休闲/地铁站）
- 通勤路线（公共交通/驾车/步行/骑行）
- 距离、测距、地图拖动缩放
- AI 辅助选位置（岗位/租房视角）
- 私人数据在地图上的聚合

## 10. 企业观察

- 27 家企业目录
- 按公司/行业/方向搜索
- 评分、规模、融资、薪资、加班、面试体验
- 企业详情、来源信息

## 11. 租房与生活

- 1810 条公开房源
- 城市/区域/租金/关键词筛选
- 分页、地图点
- 房源详情/来源链接

## 12. 面经与八股

- 只做题目检索/筛选/来源核对；收藏、待复习/错题、已掌握和学习入口统一放在“学习与刷题”，避免重复功能

- 1761 道题、6 个方向、面经/八股分类
- 搜索、方向/分类筛选、分页

## 我的数据空间

- 上传记录可撤销：删除该次上传的数据集和行
- 同一岗位/企业/租房/面经按业务主键去重：新上传覆盖旧数据，文件内重复保留最后一条
- 数据概览明确是“本账号已上传数据”的汇总，不是平台公共数据；未上传/已接入状态清晰
- AI 负责字段映射与岗位薪资归一；支持 CSV/TSV/JSON/NDJSON/XML/XLSX，自由文本需先整理成可解析记录
- 手动测试样例：[jobs-upload-sample.csv](manual-data/jobs-upload-sample.csv)
- 答案来源标记（AI 生成 / 原文有答案）
- 收藏、自评状态、学习统计
- 原始来源链接
- 学习页入口

## 13. 学习与刷题

- 原项目复习页：科目列表、版本列表
- 「问问AI」把长题以「[题目]」chip 加入知微对话，不把原文塞满输入框
- 对话输入支持 Shift+Enter 换行、随内容自动变宽到上限后增高换行，避免一按回车就发送
- 立绘和看板娘对话都支持新会话、历史会话选择/删除，刷新后保留
- 四个智能体都能根据自然语言生成自包含 HTML 页面，弹出独立网页窗口，可最小化到对话入口
- 讲题画布/3D从对话框入口弹出为独立覆盖窗口，画布约 1060px 宽、340px 高，3D 可同时渲染多个物体
- 3D 物体支持组合、位置、缩放、颜色和 opacity 透明材质（如透明正方体+球体并排）
- 右上角 − 最小化，点击对话框入口可恢复
- 学习页 iframe 保存当前科目/版本路由，刷新不会回到选择科目页
- 卡片记忆（简化/完整答案），直接显示全部，不再区分知识点/简答
- 批量简化答案一次最多 50 道，已有简化答案自动跳过；有简化答案的卡片显示标记
- 选择题、判断题、简答题、代码填空题
- 收藏、错题、答题进度、自评；收藏/错题点击有明确提示，刷新后状态和列表保留
- AI 工具圆盘：总结考点、错题精讲、简答记忆、科目关联、生成报告页、知识库问答
- 报告页持久化
- 平台题库按方向导入
- 文件题库上传
- 知识点上传
- 简答题参考答案/AI 标记

## 14. 上传题库

- 自建科目/版本可正常出现在上传页下拉框；知识点/题库上传会使用字符串版本 ID，不再因 Number 强转变成 NaN 报「版本不存在」
- 新建版本后自动选中刚创建的版本

## 15. 模拟面试

- 开始前可选择/切换任意一份简历；AI 面试官和 AI 求职者都会读取当前选中简历，切换结果本地记忆

- AI 面试官 / AI 当求职者
- 岗位、agent、风格、难度选择
- 摄像头/麦克风预览；不可用时文字降级
- 逐轮对话、语音朗读、语音识别
- 全双工实时模式（可选）
- 停顿判断（本地+小模型）
- 端侧 MediaPipe 视线/头姿/肩线/光线/动作
- 关键帧 + VLM 观察、结束反馈
- 历史记录/清除、30 天保留
- 原始音视频不落盘
- 并发保护：同时最多 3 场，第 4 场起显示队列位置，可取消；释放后自动进入

## 16. 多智能体协作气泡

- 星野、知微、砚舟、栖迟均有工作气泡；普通回复用各自配置音色朗读，协作分配/回传气泡不朗读避免叠音
- 任务可由当前 agent 规划后分派给其他 agent，气泡显示“收到任务/开始处理/结果回传”

## 17. 模拟面试音视频

- 摄像头/麦克风需 HTTPS 或 localhost；HTTPS 主服务在 5173，HTTP 兜底在 5174，首次需信任自签名证书
- 摄像头和麦克风分别申请权限；摄像头预览可拖动；麦克风开关反映真实状态，语音识别不可用时明确提示
- 结束面试即使 AI 反馈失败，也会把文字记录和占位反馈写入面试记录，不再整场丢失

## 18. AI 协作空间

- 支持新建、切换、删除多个对话；支持图片和文本/PDF/DOCX/XLSX/PPTX 附件

- 四个 agent（星野/知微/砚舟/栖迟）
- 多轮消息、历史恢复/清空
- 图片附件、文本文件附件
- PDF/DOCX/XLSX/PPTX 附件：先提取文字再作为上下文
- 多 agent 协作/规划/工具调用
- 看板娘/立绘输入框也支持文档附件
- 四个 agent 默认自动带平台公开资料 RAG；主看板娘和各立绘共用
- 工具栏不再提供独立的“知识库问答/Agent 模式”按钮，默认就是带工具与 RAG 的 agent 对话
- Agent 写操作（加入投递意向 / 提交心愿）两阶段确认：提出建议 → 用户确认 → 才写数据库
- 写操作一次性 token，绑定用户，5 分钟过期，不能跳过确认

## 16. RAG 知识库 / Tool RAG

- 混合检索：BM25 + text-embedding-v4
- RRF 融合 + qwen3-rerank
- qwen-plus 严格按片段回答、[n] 引用
- 低相关拒答、同题去重
- 公开题库/岗位/企业/房源索引；不索引私人数据
- 学习工具圆盘/看板娘 RAG 模式
- Tool RAG 按问题检索 top3 工具
- MCP JSON-RPC（initialize/tools/list/tools/call）

## 17. 心愿池（审核制）

- 用户提交后状态为审核中，可撤销；审核通过后不能删除
- 仅用户自己的待审/退回和所有已采纳可见
- 管理员审核队列：待审核/已采纳/已退回/全部
- 管理员采纳/退回、编辑、排序、删除
- 长文本展开/收起
- 5 秒同用户同文本去重

## 18. 管理中心

- 独立深色布局、管理员登录
- 运行概览、请求/内存/负载/数据库统计
- 用户账号元数据（不读简历/聊天/上传/密码）
- 编辑用户名/邮箱/角色
- 删除账号、重置密码（一次返回）
- 心愿池管理
- 系统与隐私说明

## 19. 个性化设置

- 用户名/密码
- 看板娘显示/隐藏、位置重置、音色、形象、缩放
- 主题/外观
- 账号资料

- 前后端 TypeScript/Node/SQLite
- CSRF、Origin、SameSite/HttpOnly Cookie、Secure/HSTS
- 登录/写接口/RAG/上传限流
- CSP、iframe sandbox、XSS 文本渲染、路径穿越防护
- gzip、静态缓存、构建清理
