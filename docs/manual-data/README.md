# 数据空间手动测试素材

## 岗位示例

- 文件：[jobs-upload-sample.csv](jobs-upload-sample.csv)
- 用途：数据空间 → 我的数据 → 选择文件 → 类型选“岗位” → 上传并解析。
- 表头故意不是系统标准字段（如“职位名称 / 公司名称 / 薪资范围”），用于验证 AI 字段映射。
- 文件内部有两组重复岗位：
  - 同一投递链接的 Agent 开发岗位，后一行覆盖前一行；
  - 同一公司 + 岗位 + 城市的实习岗位，后一行覆盖前一行。
- 预期：首次上传后约 5 行；再上传同一文件，旧数据集被新数据替换，仍然约 5 行。
- 所有公司、链接、地址均为虚构示例，不含真实个人信息。

## 撤销上传

上传记录 Tab 每行右侧有“撤销上传”，确认后会删除该次上传的数据集及其行。
