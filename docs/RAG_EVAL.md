## 局限

- 这是小样本回归，不是学术评测；题目仍偏“题库原题”。
- 没有覆盖多轮指代、超长文档、跨语言、对抗性 query。
- 外部模型延迟波动大；RAG 生成已限制 30s，超时返回“有来源但生成失败”的兜底。
- 后续应加 50–100 条真实用户问法，并记录 Recall@5 / MRR / 引用正确率。
