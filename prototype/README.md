# 逐光 · AI 求职助手外观原型

用于审核页面布局、功能入口与视觉风格。第二版：17个页面自由切换；移除固定Agent工位，改网页悬浮可拖动角色；个人信息统一采集，简历以文档和多版本形式展示；投递页使用独立滚动意向列表和话术编辑。大屏与学习/上传/复习直接复用原Vue页面，使用隔离预览适配器。运行检查可用 `node verify-revision.mjs`。

17个页面自由切换，不提供真实AI、登录、上传解析、匹配、地图或视频能力。角色为占位形象。

运行：`npm install`、`npm run build`、`npm start`。监听0.0.0.0:5173。验证：`node verify.mjs`，需要本机Chromium路径。

仅public目录通过HTTP提供访问；不要将密钥、私人附件和数据库放入public。原型未调用付费API。
